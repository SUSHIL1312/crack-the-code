## 🚀 Getting Started

If this directory appears empty after cloning **Crack the Code**, initialize it via Git submodule:

```bash
git submodule update --init --recursive dsa/leetcode
```

To contribute or push updates back to your LeetCode tracker:
```bash
cd dsa/leetcode
git checkout main
# ... add new problem solutions ...
git commit -m "feat(leetcode): solve Problem 123"
git push origin main
```
